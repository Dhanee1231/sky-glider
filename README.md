Sky Glider - a paper airplane racing game for kids. Play: https://dhanee1231.github.io/sky-glider/

v2: 3 difficulties (turtle / bunny / rocket), 5 worlds x 3 levels with 1-3 stars each, silly bonk-only
character obstacles, a tap-to-open mystery box after every race, a sticker album (40 stickers, 4 rarities),
coins for duplicates, a cosmetic shop (trails, hats, patterns) and an optional daily gift.
One self-contained HTML file, offline PWA, no ads, no purchases, no network calls, all art and sound made in code.
